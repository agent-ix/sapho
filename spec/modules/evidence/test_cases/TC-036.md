# TC-036: Measure declared outputs against labelled cases

## Description

Verify [the functional contract](../functional/FR-036.md) through observable public behavior with original offline inputs and injected native/backend seams only.

## Test Procedure

1. Exercise FR-036-AC-1: Known Boolean predictions produce exact TP/TN/FP/FN and agreement with explicit denominators.
2. Exercise FR-036-AC-2: Known Probability predictions produce the expected Brier score; Degree and failed/missing outputs are explicitly unscored.
3. Exercise FR-036-AC-3: Duplicate and unlabelled cases, and provenance with an unknown kind or a blank source or reference, are refused; selecting a split never evaluates cases from the other split.
4. Exercise FR-036-AC-4: A model-kind case whose source differs from the measured model identity is scored.
5. Exercise FR-036-AC-5: A model-kind case whose source equals the measured model identity is reported as `self_source` and excluded from all counts and from the exit-2 rule.

## Expected Results

Values, identity, source references, structured refusals and call counts match the declared criteria. No model quality or external integration availability is inferred from a scripted backend.

## Metadata

Type: functional/integration according to the public boundary. Priority: first CLI delivery. Tests bind the stated acceptance criteria through Trace tags.
