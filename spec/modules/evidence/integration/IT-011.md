# IT-011: Verify slice metrics and recording confidence drift

## Objective

Verify deterministic labelled slice and window comparisons and label-free recording confidence drift from synthetic public types, including absent, small and empty groups.

## Target Integration

The public pure `sapho-evidence` calculator, typed `sapho-core` Inputs and outcomes, and the CLI host's existing `sapho-recording` validation/projector boundary. No model server, clock, private EARS dataset or live passage run is required.

## Preconditions

A validated Dataset has four development cases and one Boolean output `support`. Their declared input path `repo` resolves to Text `A` on two cases and Text `B` on two. All four outcomes are completed and independent of label provenance. The host has two validated synthetic recordings with a selected binding, question and actual model.

## Inputs

Slice A has two correct Boolean predictions; slice B has one correct and one incorrect. Use minimum count 3, then 2. A separate case with absent `repo`, one with literal Text `missing`, and a wrong-typed case exercise path handling. Optional windows assign the two A cases to reference and the two B cases to current by explicit case IDs. For recording drift, reference contains selected Boolean-answer confidences `[0.6,0.8]` and current `[0.7,0.9]` under one exact Boolean Question definition; use `τ=0.8`, plus an exchange lacking the selected question and one with another binding. Separate fixtures repeat an identical successful exchange and use the same question ID under a different valid Question definition or answer kind.

## Test Procedure

1. Calculate the labelled report and inspect the overall and both value slices.
   - IT-011-SC-01: A is `2/2=1.0`, B is `1/2=0.5`, overall is `3/4=0.75`; signed agreement deltas are `+0.25` and `-0.25`, and each two-case slice is flagged too small only at minimum 3.
2. Add the absent, literal `missing` and wrong-typed path fixtures independently; compare explicit window assignments.
   - IT-011-SC-02: absent path and literal value have distinct entries; wrong type refuses with case ID/path; windows derive overall and per-slice `current - reference` without a timestamp or Dataset schema change, with absent per-slice delta when a window contains no case of that slice.
3. Add Probability cases with selected scores and inspect per-slice calibration when the shared SAPHO-21 calculator is available.
   - IT-011-SC-03: per-slice ECE and risk rows equal the shared metric over identical scored case IDs; without that calculator fields state `not_computed` and no duplicate estimator runs.
4. Project the two recordings through the host and compare confidence distributions.
   - IT-011-SC-04: reference/current means are `0.7/0.8`, shares above or equal to `0.8` are `0.5/0.5`, signed mean delta is `+0.1`, absolute mean distance is `0.1`, share distance is zero; skipped exchanges are counted explicitly.
5. Export a reference Recording containing the `0.6` exchange twice, reload it and compare without constructing a ReplayBackend.
   - IT-011-SC-05: both identical successful exchanges remain in the exported Vec and count separately; reference matching count is 3, mean is `2/3`, and share at `0.8` is `1/3`.
6. Supply two individually valid recordings whose selected question IDs match but typed Question definitions differ, then repeat with incompatible Boolean and Choice/Score answer kinds.
   - IT-011-SC-06: each mismatch refuses comparison before distance calculation; no pooled confidence or partial drift report is emitted.
7. Test an empty matching recording, invalid threshold, over-256-byte window and selector identities, and varied case/exchange insertion orders with a no-call backend double. Add a URL-shaped actual model ID, a distinct transport endpoint URL sentinel and credential sentinel in the host test fixture.
   - IT-011-SC-07: empty drift values are absent, invalid input refuses before projection, serialized ordering is identical, and the backend double is never invoked. The report preserves the exact URL-shaped model ID but contains neither the endpoint nor credential sentinel.
8. Round-trip the original Dataset JSON and inspect the evidence crate's workspace dependencies.
   - IT-011-SC-08: Dataset serde and validation decisions are unchanged; `sapho-evidence` depends only on `sapho-core` among workspace crates.

## Expected Results

Every success criterion passes. Counts and differences identify their populations and direction, missing and small groups remain visible, and recording drift contains no implied accuracy, labels or time metadata.
