# IT-017: Fit, apply and score an explicit calibration map

## Objective

Verify deterministic development-only fit, distinct calibrated typing, monotone application, map/graph identity, shared ECE parity, exact replay and side-by-side split scoring.

## Target Integration

Public sapho-core typed Value/ValueType and CalibrationMap validation; graph compiler/runtime; pure sapho-evidence fit/measure; stock CLI `fit-calibration`, `validate`, `inspect`, `replay` and `measure`. An offline scripted ModelBackend and exact Recording replace live service calls. Quoin is used only through the independent SAPHO-21 parity test already specified in IT-010; Sapho does not import Quoin.

## Preconditions

The raw graph has one Ask and raw Probability output `raw_support`; the calibration graph retains that Ask and adds a typed map literal, `calibrate` node and output `calibrated_support`. The synthetic Dataset has 20 development cases labelled for both output names, with independent human/deterministic provenance: ten raw predictions 0.05 (2 true, 8 false) and ten 0.95 (8 true, 2 false). A held-out fixture has labelled cases for both outputs and distinct case IDs. The Recording contains exactly the model requests for these cases. Shared FR-065 ECE and FR-063 graph semantic identity implementations are available before the integration case runs.

## Inputs

The 20-row development fixture, reordered outcome iteration and JSON formatting variants, a held-out fit request, under-minimum/class-degenerate/one-raw-value/unscored/self-source fixtures, a descending-rate PAVA fixture, valid and malformed map literals, two distinct downstream maps, and raw input probes at 0, 0.05, 0.5, 0.95 and 1.

## Test Procedure

1. IT-017-SC-01: Fit the 20 development rows twice with shuffled outcome-map iteration and distinct output paths. Assert identical map file bytes, `case_count=20`, knot pairs `(0.05,0.2),(0.95,0.8)`, dataset ID, development-case digest, split, raw graph semantic identity, raw output name, method and recomputed map ID. Reformat the same typed Dataset file and assert identical content digest; change one selected label and assert a different digest. Change only held-out content and assert the fit digest is unchanged.
2. IT-017-SC-02: Feed a descending empirical-rate fixture to PAVA and assert the exact pooled integer ratios and nondecreasing knots. Test equal raw values, case-ID tie order, two distinct raw values and boundary interpolation: 0/0.05 -> 0.2, 0.5 -> 0.5, 0.95/1 -> 0.8. Assert all applied outputs stay in `[0,1]` and are monotone over a dense deterministic probe set.
3. IT-017-SC-03: Fit with `--split held_out` and each insufficient, class-degenerate, unscored, failed, self-source, type-mismatched or over-4096-knot fixture. Assert a typed refusal, no output map file and zero held-out backend calls. Existing destination also refuses without overwrite.
4. IT-017-SC-04: Load the typed literal and inspect graph signatures. Assert distinct `probability`, `calibrated_probability`, `degree` and `number` ports, compile refusal on implicit raw/calibrated connections, success only through `calibrated_as_probability`, and no silent inverse conversion. Round-trip a valid map; refuse malformed version/method/split/count/digests, descending/duplicate/nonfinite/out-of-range knots and unknown fields. Assert legacy Probability and Dataset JSON/serde/validate remain stable.
5. IT-017-SC-05: Measure both named outputs on the development fixture. Assert raw Brier 0.1825 and ECE 0.15, calibrated Brier 0.16 and ECE 0 within `1e-9`, identical 20 scored case IDs/denominators and improvement at least 0.1. Run the shared FR-065 ten-case ECE test and the independent Quoin parity command/commit evidence required by IT-010; the calibrated path must call the same Sapho ECE implementation. Measure the held-out split side by side without invoking the fitter; preserve existing coverage and exit policy.
6. IT-017-SC-06: Embed two different valid maps downstream of the unchanged Ask. Assert different `graph_semantic_identity` values but identical exact recorded ModelRequest/ModelResponse replay, no ReplayMiss, and changed calibrated outputs. The map's fit graph digest still names the raw graph. Compare `GraphArtifact.source` and ordinary measure source fields to their existing path/raw-byte behavior.

## Expected Results

Every scenario has exact typed, numeric, byte, digest, error, call-count or replay evidence. Production `sapho-evidence` keeps only its `sapho-core` workspace dependency. Dataset and EARS export schemas remain unchanged; no EARS Sapho-Datasets configuration is edited.
