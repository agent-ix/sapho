# FR-036: Measure declared outputs against labelled cases

## Description

The Sapho measurement tools SHALL report agreement against explicitly curated Boolean labels with coverage and failure counts.

## Inputs

The explicit typed inputs, options and limits named in Behavior. External files and JSON/YAML are validated before evaluation.

## Outputs

The declared typed result, or a structured refusal. Execution failures retain available partial evidence; absence of a result is never interpreted as a passing evaluation.

## Behavior

Dataset is typed JSON with uniquely identified cases containing split development or held_out, typed Inputs, nonempty Boolean labels keyed by graph output, and declared label provenance/reference. Labels are supplied independently of model recordings. Dataset validation rejects duplicate IDs, empty provenance and missing labels; conversion does not promote model proposals to labels. measure explicitly selects a split and evaluates each selected case. Boolean outputs produce confusion counts and agreement; Probability outputs produce Brier score against Boolean outcome labels. Degree, Number, missing outputs and execution failures are reported as unscored/errors, never interpreted as calibrated probability. Metrics are computed separately for each named output and are never averaged across heterogeneous outputs. Each output reports total selected labelled cases, scored cases, unscored cases and failures; agreement/Brier denominators are its scored count. The measure command emits this complete report but exits 2 if any selected label is unscored or failed, otherwise 0. It does not use finding-style exit 1. Label provenance is a caller declaration; Sapho does not certify label truth or independence, and reports say agreement with supplied labels. Reports retain case IDs, predicted values, declared labels, provenance, scored counts, total selected counts and failures; denominators are explicit. Empty/unscored sets have absent metrics rather than NaN or invented accuracy.

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| FR-036-AC-1 | Known Boolean predictions produce exact TP/TN/FP/FN and agreement with explicit denominators. | Test (TC-036) |
| FR-036-AC-2 | Known Probability predictions produce the expected Brier score; Degree and failed/missing outputs are explicitly unscored. | Test (TC-036) |
| FR-036-AC-3 | Duplicate/unlabelled/provenance-free cases are refused; selecting a split never evaluates cases from the other split. | Test (TC-036) |
