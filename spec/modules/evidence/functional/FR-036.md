# FR-036: Measure declared outputs against labelled cases

## Description

The Sapho measurement tools SHALL report agreement against curated Boolean labels whose provenance declares the label's kind and source, with coverage and failure counts.

## Inputs

The explicit typed inputs, options and limits named in Behavior. External files and JSON/YAML are validated before evaluation.

## Outputs

The declared typed result, or a structured refusal. Execution failures retain available partial evidence; absence of a result is never interpreted as a passing evaluation.

## Behavior

Dataset is typed JSON with uniquely identified cases containing split development or held_out, typed Inputs, nonempty Boolean labels keyed by graph output, and label provenance. Provenance declares a kind, one of `model`, `agent`, `human` or `deterministic_check`; a nonblank source naming who made the labels (for kind `model`, the model identity the backend reported for the answer); and a nonblank reference saying where the labels came from. A model answer is a valid label when its provenance declares kind `model` and its source. Dataset validation rejects duplicate IDs, missing labels, a kind outside the four, and a blank source or reference. The measurement exclusion rule compares declared provenance with the run's reported model identity: when a case's provenance kind is `model` and its source equals the model name reported by any response during evaluation, no output of that case is scored. The case is reported as `self_source` with its case ID, is excluded from labelled, scored and unscored counts, and does not by itself cause exit 2. Different model names do not prove source independence because aliases can share the same source. Callers must treat scores as source-uncertain unless they can establish independence from evidence outside Sapho ([FR-052](../../ollama/functional/FR-052.md)). No new version field is required. measure explicitly selects a split and evaluates each selected case. Boolean outputs produce confusion counts and agreement; Probability outputs produce Brier score against Boolean outcome labels. Degree, Number, missing outputs and execution failures are reported as unscored/errors, never interpreted as calibrated probability. Metrics are computed separately for each named output and are never averaged across heterogeneous outputs. Each output reports total selected labelled cases, scored cases, unscored cases and failures; agreement/Brier denominators are its scored count. The measure command emits this complete report but exits 2 if any selected label is unscored or failed, otherwise 0. It does not use finding-style exit 1. Label provenance is a caller declaration; Sapho does not certify label truth, and reports say agreement with supplied labels. Reports retain case IDs, predicted values, declared labels, provenance kind, source and reference, self_source exclusions, scored counts, total selected counts and failures; denominators are explicit. Empty/unscored sets have absent metrics rather than NaN or invented accuracy.

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| FR-036-AC-1 | Known Boolean predictions produce exact TP/TN/FP/FN and agreement with explicit denominators. | Test (TC-036) |
| FR-036-AC-2 | Known Probability predictions produce the expected Brier score; Degree and failed/missing outputs are explicitly unscored. | Test (TC-036) |
| FR-036-AC-3 | Duplicate and unlabelled cases, and cases whose provenance has an unknown kind or a blank source or reference, are refused; selecting a split never evaluates cases from the other split. | Test (TC-036) |
| FR-036-AC-4 | A case with provenance kind `model` and a declared source validates and is scored when the measured run's model identity differs from that source. | Test (TC-036) |
| FR-036-AC-5 | A case with provenance kind `model` whose source equals the measured run's reported model name is reported as `self_source`, is absent from every labelled, scored and unscored count, and alone does not make measure exit 2; a different model name alone does not prove source independence. | Test (TC-036) |
