# FR-038: Export curated training cases

## Description

The Sapho training export SHALL emit explicitly selected labelled development cases with provenance.

## Inputs

The explicit typed inputs, options and limits named in Behavior. External files and JSON/YAML are validated before evaluation.

## Outputs

The declared typed result, or a structured refusal. Execution failures retain available partial evidence; absence of a result is never interpreted as a passing evaluation.

## Behavior

export-training reads and validates a dataset, selects development cases and emits JSONL records containing original case identity, typed inputs, Boolean output labels and label provenance. Held-out cases are never included. This is a model-independent interchange of curated supervision; downstream trainers own model-specific prompt/completion conversion and training execution. The command performs no inference or automatic training and uses bounded exclusive output writes. The command refuses datasets with no selected labelled development cases.

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| FR-038-AC-1 | An export contains only the declared development rows with original identity, inputs, labels and provenance. | Test (TC-038) |
| FR-038-AC-2 | Held-out rows and model-recording-only/unlabelled payloads are excluded or refused rather than promoted to supervision. | Test (TC-038) |
| FR-038-AC-3 | Empty exports, oversized datasets and existing output destinations fail explicitly without starting a model or trainer. | Test (TC-038) |
