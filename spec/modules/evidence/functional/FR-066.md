# FR-066: Report risk and coverage at confidence thresholds

## Description

When `measure` scores a Probability output, the evidence calculator SHALL report a threshold-indexed risk-coverage table from the same predicted-label confidence and correctness observations as ECE.

## Inputs

The scored Probability observations defined by [FR-065](FR-065.md), and optional caller-specified thresholds. The existing `measure` call uses the default thresholds.

## Outputs

For each Probability output with at least one scored case, ordered rows containing threshold, answered, correct, total, coverage, optional accuracy and optional risk. An output with no scored Probability cases has an empty table.

## Behavior

The calculator SHALL use default thresholds `[0.5, 0.6, 0.7, 0.8, 0.9, 0.95]` unless a caller selects a custom threshold list through a separate pure evidence API.

The calculator SHALL require a nonempty, strictly increasing list of at most 32 finite thresholds within `[0.5,1.0]`; invalid lists cause a structured refusal before scoring.

For each threshold `t`, the calculator SHALL set total to the Probability output's scored count and answered to the count of those observations whose confidence is `>= t`.

For each threshold, the calculator SHALL set correct to the number of answered observations whose predicted Boolean agrees with the supplied label.

The calculator SHALL compute coverage as `answered/total`, accuracy as `correct/answered`, and risk as `1-accuracy`; accuracy and risk are absent when answered is zero.

The calculator SHALL preserve caller threshold order in the table. It SHALL not include missing, failed, unsupported, type-mismatched or self-source-excluded cases in total.

The calculator SHALL compute each named output independently and keep the existing Dataset JSON shape, validation, split selection, Brier and report coverage counts unchanged.

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| FR-066-AC-1 | The IT-010 ten-case fixture yields exact `(answered,correct,total)` rows `(10,6,10)`, `(8,5,10)`, `(6,3,10)`, `(4,3,10)`, `(3,2,10)`, `(2,1,10)` at default thresholds in order; coverage, accuracy and risk match those counts. | Test |
| FR-066-AC-2 | A custom threshold equal to a scored confidence includes that case; a higher threshold excludes it, and no-answered rows have zero coverage with absent accuracy and risk. | Test |
| FR-066-AC-3 | Empty, duplicate, descending, nonfinite, out-of-range or more-than-32 thresholds refuse before scoring with a stable error; a valid override changes only the requested table. | Test |
| FR-066-AC-4 | A Probability output with no scored cases has an empty table; Degree and Number outputs receive no risk-coverage table and remain unscored under the existing contract. | Test |
| FR-066-AC-5 | A case labelled by the answering model and a case in the unselected split affect neither the table total nor any threshold count; existing measure coverage and exit policy remain unchanged. | Test |

## Dependencies

[FR-036](FR-036.md) defines selected and scored cases. [FR-065](FR-065.md) defines confidence and correctness. The table follows Quoin `coverage_curve`'s inclusive threshold count rule without adding Quoin as a dependency.
