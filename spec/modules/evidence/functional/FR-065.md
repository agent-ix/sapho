# FR-065: Measure probability calibration against declared labels

## Description

When `measure` scores a Probability output against curated Boolean labels, the evidence calculator SHALL report expected calibration error (ECE) using the predicted label's confidence and the `jev.ece-v1` count-weighted decile definition.

## Inputs

The existing validated Dataset, selected split, output schema, checked per-case outcomes and self-source exclusions supplied to `measure`.

## Outputs

For each Probability output, an optional ECE and ten decile summaries with bounds, scored count, correct count, mean confidence and observed accuracy for occupied buckets. Empty buckets have count zero and absent means. The existing Brier, coverage, prediction and provenance fields remain available.

## Behavior

For each scored Probability value `p`, the calculator SHALL predict `true` when `p >= 0.5` and `false` otherwise.

The calculator SHALL set confidence to `max(p, 1-p)` and correctness to whether that predicted Boolean equals the case label.

The calculator SHALL place confidence `c` in decile `min(floor(10c), 9)`, representing `[i/10,(i+1)/10)` for `i<9` and `[0.9,1.0]` for `i=9`. Thus `c=0.9` and `c=1.0` both enter the last bucket.

For each occupied bucket, the calculator SHALL use the mean of its actual confidence values and its correct-count divided by count.

The calculator SHALL not substitute a bucket midpoint.

The calculator SHALL compute ECE as `sum_bucket (bucket_count / scored_count) * abs(bucket_mean_confidence - bucket_accuracy)`.

When no case is scored for a Probability output, the calculator SHALL report ECE absent rather than zero and all bucket means absent.

The calculator SHALL exclude Degree, Number, Boolean, missing, failed, type-mismatched and self-source-excluded predictions from ECE.

The calculator SHALL preserve their existing measurement coverage behavior.

The implementation SHALL reside in pure `sapho-evidence`, with `sapho-core` as its only workspace-crate dependency.

It SHALL preserve the existing Dataset JSON shape, serde, `Dataset::validate` and `measure` call signature.
