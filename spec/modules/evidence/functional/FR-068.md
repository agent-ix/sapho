# FR-068: Compare confidence distributions without labels

## Description

When a caller supplies two validated sets of successful recorded exchanges, the evidence calculator SHALL report label-free confidence drift for one declared binding, question and actual model without inferring accuracy or calibration.

## Inputs

A reference recording and current recording, caller-supplied distinct window names, exact backend binding ID, question ID and actual reported model ID, and one finite threshold `τ` in `[0,1]`. The CLI host validates and projects the recordings into bounded confidence observations; the pure evidence crate receives only those observations and metadata, not `sapho-recording` types or raw bodies.

## Outputs

A deterministic report with selector, threshold, window names, each window's retained-exchange count, matching-question count, mean confidence and share with confidence `>= τ` when nonempty, signed `current - reference` differences and absolute distances for those two statistics when both exist, and explicit absent reasons otherwise. No label, accuracy, risk, ECE or raw request/response body is synthesized.

## Behavior

The CLI SHALL validate each recording with its existing byte ceiling and recording validation rules before extracting observations.

For each retained successful exchange matching the binding and actual model, the host SHALL select only the declared question ID's answer.

It SHALL count exchanges without that question as skipped rather than as confidence zero.

For a Boolean answer with probability `p`, the host SHALL extract predicted-label confidence `max(p,1-p)`.

For a Choice or Score answer, the host SHALL extract its validated reported confidence.

The host SHALL pass only bounded window identity, selector and finite unit-range confidence values to the pure evidence calculator.

It SHALL exclude raw bodies, label data, credentials and URLs.

The calculator SHALL count each retained matching exchange once per supplied recording set. It SHALL not claim invocation-frequency coverage because exact recording export can deduplicate repeated exchanges.

For each nonempty window, the calculator SHALL compute mean confidence as the sum of confidences divided by matching-question count and high-confidence share as count with confidence `>= τ` divided by matching-question count.

The calculator SHALL sum confidence values in ascending numeric order within each window so recording-exchange permutations yield the same serialized result.

When both windows are nonempty, the calculator SHALL report signed differences as current minus reference and absolute distances as the absolute values of those differences.

When either window is empty, the calculator SHALL leave differences and distances absent with an `insufficient_observations` reason rather than emit zero drift.

The calculator SHALL make no model, filesystem or clock call. Window names describe caller-supplied recording sets; no timestamp is inferred from recording content or order.

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| FR-068-AC-1 | Synthetic reference confidences `[0.6,0.8]` and current `[0.7,0.9]` at `τ=0.8` produce means `0.7` and `0.8`, high-confidence shares `0.5` and `0.5`, signed mean delta `+0.1`, absolute mean distance `0.1`, and zero share distance. | Test |
| FR-068-AC-2 | A confidence equal to `τ` is counted high; missing question and nonmatching binding/model exchanges are skipped with explicit counts, not treated as zero confidence. | Test |
| FR-068-AC-3 | An empty matching window reports absent means, shares, differences and distances with `insufficient_observations`, not perfect stability. | Test |
| FR-068-AC-4 | Invalid recording, nonfinite/out-of-range threshold or confidence, or missing selector refuses before comparison; no raw body, credential, URL, label or invented timestamp enters the report. | Test |
| FR-068-AC-5 | Reordered retained exchanges produce the same serialized report; the comparison makes no model call and adds no `sapho-recording` dependency to `sapho-evidence`. | Test |
