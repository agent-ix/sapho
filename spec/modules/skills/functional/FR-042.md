# FR-042: Package graph authoring workflows

## Description

The Sapho plugin SHALL expose create, tune and record skills around the public CLI.

## Inputs

The explicit typed inputs, options and limits named in Behavior. External files and JSON/YAML are validated before evaluation.

## Outputs

The declared typed result, or a structured refusal. Execution failures retain available partial evidence; absence of a result is never interpreted as a passing evaluation.

## Behavior

A portable plugin manifest and skills/create, skills/tune and skills/record/SKILL.md are maintained as original Sapho assets. create translates the requested evaluation into YAML/JSON, makes types/guards/combiners and output meaning explicit, validates it, and explains custom-host needs. tune obtains declared development labels, runs measure/tune, retains candidate evidence and held-out separation, and reports changes without claiming accuracy from unlabelled scores. record invokes explicit bounded capture and explains private/local retention, failures and replay identity. Skills use actual public command syntax and references to this repository's guide, rather than duplicating a second evaluator or installing scripts/hooks. Model calls, writes, publication and training continue to follow user/session authorization. Training exports are curated data, not model-ground-truth conversion. Packaging validation and offline forward examples use the CLI; installation/enforcement and public plugin publication are not part of this delivery.

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| FR-042-AC-1 | The plugin resolves exactly the three valid skills and their repository-owned references without path escape or missing artifacts. | Test (TC-042) |
| FR-042-AC-2 | A creation example yields a validated YAML graph; a tuning example preserves held-out separation and reports labelled metrics. | Test (TC-042) |
| FR-042-AC-3 | A recording example uses explicit artifact destinations and exact replay; the package contains no automatically installed enforcement hooks. | Test (TC-042) |
