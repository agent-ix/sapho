# StR-010: Author and tune evaluations with an agent

## Stakeholder Need

The graph author requires that Sapho shall make ask an agent to create, record and tune an evaluation possible while retaining typed results and attributable evidence.

## Rationale

The existing embedding engine already evaluates code, model and logic stages. The user needs a reusable workflow around that engine, with domain meaning owned by the consumer.

## Validation Criteria

| ID | Criteria | Validation |
|----|----------|------------|
| StR-010-VC-1 | A documented example produces observable results through the owning module's public contract. | Demonstration |
| StR-010-VC-2 | Invalid input is distinguishable from a completed evaluation and never silently repaired. | Demonstration |
