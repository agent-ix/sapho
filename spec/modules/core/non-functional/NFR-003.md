# NFR-003: Secret-free engine artifacts

## Statement

The Sapho serialized engine artifacts SHALL exclude credential material from their declared fields.

## Scope

Graph, values, traces and recordings declare no API-key, auth-header or environment-secret field. The Jev SDK client owns auth. Application-supplied state is opaque content and can contain sensitive facts; the caller chooses what to send and retain. Sapho does not auto-publish, write traces or read secrets. Private recordings remain outside Git working trees.

## Measurement and Evaluation

| Metric | Target | Threshold | Method |
|--------|--------|-----------|--------|
| Credential-bearing engine fields | 0 | 0 | Test and inspection |

## Verification

Run the scoped crate tests and inspect the dependency/serialization surfaces. At handoff run format, all-target/all-feature clippy, full workspace tests, documentation and supply-chain gates; no live calls are needed.
