# StR-001: Typed values, evidence and extension contracts

## Stakeholder Need

The Sapho engine SHALL exchange typed facts and judgments between reusable components.

## Rationale

This separates reusable engine mechanics from consumer policy so that domain-specific concepts can remain in my application.

## Validation Criteria

| ID | Criteria | Validation |
|----|----------|------------|
| StR-001-VC-1 | An application composes this capability using declared engine interfaces. | Demonstration |
| StR-001-VC-2 | An invalid invocation reports its cause without a fabricated successful result. | Demonstration |

## Stakeholders

Application authors and investigators consuming Sapho as Rust libraries.
