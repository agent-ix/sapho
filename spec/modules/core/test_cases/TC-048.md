# TC-048: Define a one-call structured extraction port

## Description

Verify every acceptance criterion of [FR-048](../functional/FR-048.md) through the public core boundary with the scripted Extractor double; no transport is involved.

## Test Procedure

1. Exercise FR-048-AC-1: script a schema-valid value and assert value, usage, raw bytes and model identity reach the caller unchanged.
2. Exercise FR-048-AC-2: script a schema-violating value and non-JSON bytes; assert `InvalidAnswer`, the violation pointer and the retained raw exchange.
3. Exercise FR-048-AC-3: script `TooLarge`, `BackendFailed`, `DeadlineExceeded` and `LimitExceeded`; assert each code is distinguishable.
4. Exercise FR-048-AC-4: submit each invalid request; assert `Config` and zero recorded requests.
5. Exercise FR-048-AC-5: use the double from an integration test crate and assert the recorded request order.
6. Exercise FR-048-AC-6: inspect the core manifest's dependencies.

## Expected Results

Every value, code, pointer and recorded request matches the functional criteria. No model quality is inferred from scripted responses.
