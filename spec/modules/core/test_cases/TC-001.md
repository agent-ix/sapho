# TC-001: Validate typed values

## Description

Verify every acceptance criterion of [FR-001](../functional/FR-001-validate-typed-values.md) through the public crate boundary, using offline transports for model paths.

## Test Procedure

1. Exercise FR-001-AC-1: A declared record and nested list round-trip with their exact values and item IDs.
2. Exercise FR-001-AC-2: NaN, infinity, out-of-range probabilities/degrees and invalid source ranges return InvalidValue; duplicate item IDs return DuplicateId and wrong record fields return TypeMismatch.
3. Exercise FR-001-AC-3: Optional absence is accepted only for Optional ports; a 33-level value is rejected without a panic.

## Expected Results

The observable values, refusal codes, preserved identities and call counts match the functional criteria. A missing assertion is not evidence. Model quality is not inferred from scripted responses.
