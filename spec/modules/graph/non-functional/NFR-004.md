# NFR-004: Supported Rust toolchain

## Statement

The Sapho workspace SHALL build on Rust 1.98.1 with edition 2024.

## Scope

The inspected TypeSafe SDK 0.6.2 declares Rust 1.98. Pin 1.98.1 rather than the scaffold stable default. Tests for core/graph/runtime/recording require no running model, key or network. Jev contract tests inject an SDK transport; live inference is an opt-in consumer concern.

## Measurement and Evaluation

| Metric | Target | Threshold | Method |
|--------|--------|-----------|--------|
| Required live model calls during default tests | 0 | 0 | Test and inspection |

## Verification

Run the scoped crate tests and inspect the dependency/serialization surfaces. At handoff run format, all-target/all-feature clippy, full workspace tests, documentation and supply-chain gates; no live calls are needed.
