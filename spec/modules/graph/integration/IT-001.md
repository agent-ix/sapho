# IT-001: Native code composition

## Objective

Verify native code composition through actual public crate interfaces.

## Target Integration

The owning crate and its declared prerequisite crates, with a model backend or SDK transport injected only at the external inference seam.

## Preconditions

Rust 1.98.1; no model server or credentials. Original synthetic test inputs only.

## Inputs

A configured graph, supplied Datum inputs, registered native primitives and finite run limits.

## Test Procedure

1. IT-001-SC-01: Register a native transform, load YAML/JSON naming it, compile and run valid/invalid ports.
2. IT-001-SC-02: Assert concrete output values, source IDs, refusal codes and external call counts.

## Expected Results

The transform is called only after successful compilation; invalid outputs are refused.
