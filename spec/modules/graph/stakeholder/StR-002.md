# StR-002: Declarative graph definition and compilation

## Stakeholder Need

The Sapho engine SHALL describe a composable judgment procedure and detect invalid connections before running it.

## Rationale

This separates reusable engine mechanics from consumer policy so that I can change its wiring without rewriting the execution machinery.

## Validation Criteria

| ID | Criteria | Validation |
|----|----------|------------|
| StR-002-VC-1 | An application composes this capability using declared engine interfaces. | Demonstration |
| StR-002-VC-2 | An invalid invocation reports its cause without a fabricated successful result. | Demonstration |

## Stakeholders

Application authors and investigators consuming Sapho as Rust libraries.
