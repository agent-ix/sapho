# FR-039: Select bounded attributable files

## Description

The Sapho file selector SHALL gather UTF-8 regular files under an explicit root into deterministic identified units.

## Inputs

The explicit typed inputs, options and limits named in Behavior. External files and JSON/YAML are validated before evaluation.

## Outputs

The declared typed result, or a structured refusal. Execution failures retain available partial evidence; absence of a result is never interpreted as a passing evaluation.

## Behavior

files takes an explicit root, include/exclude glob patterns and an output port. Root-relative slash-separated paths are sorted lexically; duplicate matches are deduplicated. Default excludes .git; symlinks and non-regular entries are skipped and never followed. Explicit root validation and canonical paths prevent escaping that root. A selected unreadable, invalid-UTF-8 or NUL-containing file refuses the acquisition; content is not silently omitted/cropped. Each unit is a Record with path, text and status present, has an ID derived from its relative path, and has a SourceRef covering the exact gathered bytes under a content-identified source. Empty selection is an identified empty list. File count, visited-entry, per-file, cumulative-byte and duration ceilings are explicit.

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| FR-039-AC-1 | Include/exclude patterns yield sorted unique records with exact text, stable IDs and byte-accurate source references. | Test (TC-039) |
| FR-039-AC-2 | Empty selections are valid; symlink/outside-root/non-regular entries are never read; selected binary/unreadable data is refused. | Test (TC-039) |
| FR-039-AC-3 | File/entry/byte/deadline ceilings refuse incomplete acquisition without truncating any returned context. | Test (TC-039) |
