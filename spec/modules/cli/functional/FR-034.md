# FR-034: Invoke bounded graphs from data

## Description

The Sapho CLI SHALL execute the compiled engine with explicitly supplied data, bindings and resource ceilings.

## Inputs

The explicit typed inputs, options and limits named in Behavior. External files and JSON/YAML are validated before evaluation.

## Outputs

The declared typed result, or a structured refusal. Execution failures retain available partial evidence; absence of a result is never interpreted as a passing evaluation.

## Behavior

run accepts a graph path, --input file or - for stdin, optional --typed-input, --bindings file, output/trace destinations, finite run limit flags and optional --fail-on Boolean output. Plain input JSON is a map of exact input port names decoded against compiled schemas; typed mode accepts the existing Inputs representation and preserves explicit IDs/sources. The synchronous command host reads bounded inputs before entering the async executor and persists results after it exits; it never nests block_on inside an async worker. Bindings are YAML/JSON data naming provider jev, model, optional expected_model and DistributionPolicy, with no credential fields. The optional jev feature uses the existing SDK environment configuration; no-feature builds refuse requested live providers. Custom hosts may inject backends. Completed runs return typed outputs and trace; failures retain partial trace and a structured error. stdout is machine-readable JSON, diagnostics go to stderr, success exits 0, explicit true fail-on exits 1, and configuration/acquisition/execution refusal exits 2. A false fail-on returns 0; absent or non-Boolean selected outputs are errors. No implicit model retry, shell execution or persistence occurs.

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| FR-034-AC-1 | File and stdin plain/typed inputs execute an offline graph with equivalent values and correct fail-on exit codes. | Test (TC-034) |
| FR-034-AC-2 | Invalid ports/types, unknown bindings, missing features and exhausted limits produce structured refusals and partial evidence where available. | Test (TC-034) |
| FR-034-AC-3 | An injected backend/native seam executes multi-layer work without any filesystem blocking on the async worker; stdout contains only the bounded typed report. | Test (TC-034) |
