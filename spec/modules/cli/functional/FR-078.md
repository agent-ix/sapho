# FR-078: Publish validated router and escalation graphs

## Description

When the exact-one merge is available, the Sapho examples and user guide SHALL show a runnable three-backend router and the existing guarded escalation pattern. CI compiles both graphs offline under the Behavior contract below.

## Inputs

`examples/graphs/router.yaml` and `examples/graphs/escalation.yaml`, linked from `docs/user-guide.md`; synthetic typed inputs and scripted/recorded backend responses for integration tests. The graphs use the public declarative schema and do not contain credentials, endpoints or quality claims.

## Outputs

Two graph files that pass `sapho validate`, user-guide links and instructions, and a CI check that rejects syntax or type regressions.

## Behavior

The router graph SHALL compute three exclusive Boolean guards from an item feature and explicit low/high profile thresholds using `compare`, `and` and `not`, then guard three Asks with arbitrary BackendIds such as `tier_a`, `tier_b` and `tier_c`. No Ask is unguarded. It SHALL merge Answers and model Text separately with `merge_present`, expose both as outputs, and feed Answers to `probability`. The guide SHALL explain the exact-one error for gaps and overlaps, the 2–32 bound, backend configuration outside graph literals, and how to adapt the threshold profile without implying that the router learns or assesses model quality.

The escalation graph SHALL keep the existing fast Ask unguarded, guard the expert Ask by an explicit threshold condition, and use `coalesce` for both Answers and model Text. It SHALL preserve the current worked behavior: confident cases call only fast; escalated cases call fast then expert. The guide SHALL link this example and distinguish its call pattern from the mutually exclusive router.

The repository CI path SHALL run `sapho validate examples/graphs/router.yaml` and `sapho validate examples/graphs/escalation.yaml` through `make docs-examples` or an equivalent explicit CI step. The check SHALL compile without credentials or live model calls. Existing example validation remains active. Documentation link checking SHALL cover both user-guide links.

| FR-078-AC-2 | The router example has three mutually exclusive guarded Asks, no default Ask, separate Answers/Text merges and a downstream probability projection; replay across three synthetic items yields one call and two Skipped traces per item. | Test (IT-015) |
| FR-078-AC-3 | The escalation example and guide show fast-only versus fast-plus-expert calls; replay confirms coalesced Answers and Text and preserves existing guarded escalation behavior. | Test (IT-015) |
| FR-078-AC-4 | The guide states zero/multiple-present `InvalidValue`, the 2–32 limit and that backend IDs are configured by the host; documentation link checking accepts both links. | Test (IT-015) |
