# FR-045: Resolve host provider credentials through shared secrets

## Description

When the CLI prepares a required live provider, the CLI SHALL resolve its credential using ix-cli-kit shared secrets before asynchronous evaluation.

## Inputs

Checked core requests or host-selected configuration; untrusted bytes are bounded and validated.

## Outputs

Typed responses or a structured refusal; private contents are excluded from diagnostics.

## Behavior

The application scope is agent-ix/sapho, keys clm-api-key and jev-api-key, environment variables CLM_API_KEY and TYPESAFE_API_KEY. Explicit embedding-host credentials take precedence over the environment, which takes precedence over OS storage. CLI never accepts secrets in graph/binding/recording documents or argv. CLM auth is optional when storage returns absence; Jev requires a credential. Locked/unavailable/backend/invalid-environment errors remain distinguishable typed refusals; there is no file fallback. Endpoint resolution uses shared flag > environment > file > default mechanism where sources exist; stock live providers currently use environment > default with CLM_BASE_URL default http://127.0.0.1:8700 and existing Jev SDK endpoint configuration. Only required bindings prepare live transports. The CLI disables SDK transport logging even when the environment requests debug, so request/response contents and headers never reach diagnostics. Provider metadata supports Jev and Clm and defaults CLM model to clm-latest; Jev model omission refuses. Missing compiled provider support refuses before credential access.

Replay infers only (model, expected_model, distribution_policy) per backend and compares explicit metadata on those fields, never a guessed provider. Explicit metadata for absent exchanges supplies identity only. Validation, inspection, replay and replay-backed measure/tune never construct a live provider, read credential environment, access OS storage or network. Changes to core Usage are coordinated with downstream Rust consumers; no consumer source is copied.
