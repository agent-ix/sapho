# FR-090: Prepare Claude only for required live bindings

## Description

When a graph requires a live `claude` binding, the stock CLI SHALL attach its bounded adapter through the existing backend registry and leave offline paths credential-free.

## Inputs

Existing binding metadata with `provider: claude`, explicit nonempty model, optional `expected_model` and DistributionPolicy. Endpoint, credential and workspace ID fields are forbidden in graph, binding and recording files and argv. Live secret resolution uses existing `agent-ix/sapho` shared-secret scope with key `anthropic-api-key`: explicit embedding-host secret > `ANTHROPIC_API_KEY` environment > OS storage. The stock CLI obtains an optional workspace ID only from the host environment variable `ANTHROPIC_WORKSPACE_ID`, when a required live Claude binding is prepared; a caller with a multi-workspace or identity-linked key must set it. Empty/invalid values refuse before send.

## Outputs

A `sapho-claude` ModelBackend registry entry or typed configuration/credential/feature refusal before network access.

## Behavior

The CLI SHALL expose Claude as an optional compiled provider feature, disabled by default, and use the fixed production URL and FR-089 default limits. It SHALL prepare only bindings required by live `run` or `record`; unused metadata reads no secret, workspace environment variable or network. Missing feature, model or key; invalid secret/workspace ID; and endpoint, credential or workspace fields in metadata refuse before send. No Claude-specific graph operation, model hardcode, secret argv flag or provider-specific replay format is introduced. `validate`, `inspect`, `replay`, replay-backed `measure` and `tune` use no live provider, credential store, workspace environment variable or network. Exact recording retains core ModelRequest, reported actual-model ModelResponse and RawExchange; replay derives only the existing `(backend, requested model, expected model, DistributionPolicy)` identity and produces the same answers/usage without the Claude feature/key/service. Existing Jev, CLM, Decisions and generic replay behavior remains unchanged.

| FR-090-AC-2 | Swapping only provider/model binding metadata sends the same graph Ask to a different backend; omitted model, missing key, invalid metadata secret/endpoint/workspace fields refuse before transport. | Test (IT-019) |
