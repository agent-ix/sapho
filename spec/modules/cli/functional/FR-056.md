# FR-056: Evaluate and tune datasets of about fifteen thousand cases with explicit ceilings

## Description

The Sapho CLI SHALL keep its case and byte ceilings as safety bounds with their present defaults; the CLI guide documents, and a test exercises, the explicit flag values with which `measure` and `tune` evaluate a labelled Dataset of 15,000 cases without a limit error, while a Dataset above the configured ceiling is still refused.

## Inputs

- A labelled Dataset of 15,000 cases, and the flags `--max-cases` and `--max-artifact-bytes` of `measure`, `tune` and `export-training` ([NFR-005](../non-functional/NFR-005.md)).

## Outputs

The report, tuning and recording of the commands, or the refusal `CaseLimit` (case count) or a byte-ceiling refusal, each naming its limit.

## Behavior

A labelled Dataset can hold about fifteen thousand cases, which is more than the default of 1024 cases and the default artifact ceiling of 8 MiB. The ceilings exist so that no run silently takes unbounded work, and NFR-005 already makes a larger ceiling an explicit invocation, never a hidden retry; so the defaults stay, the invocation for a large Dataset is written down and tested, and the user chooses the ceiling knowingly. A Dataset is not sharded: the command reads one file.

- The CLI SHALL keep the defaults of `--max-cases` (1024) and `--max-artifact-bytes` (8 MiB).
- The CLI SHALL accept larger positive values for both on `measure`, `tune` and `export-training`.
- The CLI guide SHALL give the invocation for a Dataset of up to 20,000 cases, with `--max-cases 20000` and a `--max-artifact-bytes` value (for example 1073741824, 1 GiB) at least the size of the Dataset file, of the recording and of the report.
- The CLI guide SHALL state that the artifact ceiling bounds each of those files separately.
- The CLI SHALL refuse a Dataset with more cases than `--max-cases` with `CaseLimit` naming the limit, before any model call.
- The CLI SHALL refuse a file larger than `--max-artifact-bytes`, naming the limit, before it parses it; neither refusal truncates or retries.
- With the documented flags, `measure` and `tune` over 15,000 cases SHALL complete with the scripted backend of the test suite, giving a report whose case count is 15,000, with no limit error.
- The peak resident memory of that run SHALL stay at or below six times the size of the Dataset file plus 64 MiB, as the operating system reports it for the process.
- The per-case results of `measure` SHALL NOT depend on how the cases are split into files: a case gives the same result in a file of 600 cases as in a file of 1,200.
- A caller that splits a very large Dataset combines the aggregates of the per-file reports from their case counts; agreement and Brier combine as case-weighted means and calibration bins by adding their counts, and the CLI itself does not shard or combine.

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| FR-056-AC-1 | A generated 15,000-case Dataset runs through `sapho measure` and `sapho tune` with the documented flags, using an offline scripted backend, and the report counts 15,000 cases with no limit error. | Test |
| FR-056-AC-2 | The same Dataset without the flags is refused with `CaseLimit` naming 1024 before any model call, and a Dataset file larger than a lowered `--max-artifact-bytes` is refused naming that limit; nothing is truncated. | Test |
| FR-056-AC-3 | The defaults remain 1024 cases and 8 MiB; `sapho measure --help` shows both flags with those defaults, and the CLI guide shows the documented invocation for 20,000 cases. | Test |
| FR-056-AC-4 | Two disjoint 600-case files measured separately give per-case results equal to those of the 1,200-case union measured as one file, case for case. | Test |
| FR-056-AC-5 | The test harness measures the peak resident memory of the 15,000-case `measure` run and fails when it exceeds six times the Dataset file size plus 64 MiB; the measured peak and the run time are recorded in the change that implements this requirement, and no output file exceeds the byte ceiling the guide documents. | Test |
