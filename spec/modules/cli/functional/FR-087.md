# FR-087: Prepare a Decisions binding only for required live inference

## Description

When a graph requires a live `decisions` provider binding, the stock CLI SHALL resolve its credential and attach the verified adapter without changing offline command behavior.

## Inputs

Existing provider binding metadata with `provider: decisions`, explicit `model: gpt-6-luna`, optional `expected_model` and explicit DistributionPolicy. No endpoint, API key or transport override is allowed in graph, binding or recording documents. Credential resolution uses existing `agent-ix/sapho` shared secret scope with key `openai-api-key`: explicit embedding-host secret > `OPENAI_API_KEY` environment > OS secret storage. The stock CLI has no secret argv flag.

## Outputs

A core BackendRegistry entry with one `sapho-decisions` ModelBackend, or a typed configuration/credential/provider-feature refusal before network access.

## Behavior

The CLI SHALL make `decisions` an optional compiled provider feature, disabled by default. It SHALL reject absent feature, missing/invalid credential, omitted/wrong model, endpoint/credential fields and unavailable required binding before constructing live transport. It SHALL prepare only bindings required by a live `run` or `record` graph; unused metadata triggers no secret lookup or network work. Provider-specific `OPENAI_API_KEY` is read only when that live binding is required. The fixed production URL and FR-086 bounded defaults apply; no caller-controlled base URL is exposed in stock CLI.

`validate`, `inspect`, `replay` and replay-backed `measure`/`tune` SHALL remain offline and credential-free. Replay infers existing `(backend, requested model, expected model, DistributionPolicy)` metadata from exact recorded requests, without needing the live provider feature or a provider name. Explicit replay metadata compares only those existing identity fields. Successful live `record` captures exact Decisions ModelRequest/ModelResponse and RawExchange, and exact replay reconstructs identical Answers and usage without OpenAI access. Dataset JSON/serde/validate and EARS export are unchanged.

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| FR-087-AC-1 | Required live `decisions` binding resolves explicit > environment > OS secret under the declared scope/key; unused binding, absent feature and all offline commands make zero credential/network calls. | Test (IT-018) |
| FR-087-AC-2 | Omitted/wrong model, missing/invalid key, endpoint or credential in metadata and unsupported provider feature refuse before request; graph and recording contain no credential. | Test (IT-018) |
| FR-087-AC-3 | Live synthetic capture then replay produces byte-identical typed Answers/usage and exact request identity without provider feature, credential environment or network; mismatched explicit replay identity refuses. | Test (IT-018) |
