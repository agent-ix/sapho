# FR-033: Inspect a graph without executing it

## Description

The Sapho CLI SHALL validate and inspect graph contracts without evaluating native code or models.

## Inputs

The explicit typed inputs, options and limits named in Behavior. External files and JSON/YAML are validated before evaluation.

## Outputs

The declared typed result, or a structured refusal. Execution failures retain available partial evidence; absence of a result is never interpreted as a passing evaluation.

## Behavior

validate and inspect load a graph, compile with the host PrimitiveRegistry, and report declared inputs, outputs, stable dependency stages and required backend/primitive names. A custom Rust host can register primitives using the same public invocation library; the stock executable has no domain registry. Unknown primitive names refuse compilation and are not replaced by stubs. Backend names can be reported without credentials or transport construction. File extension selects yaml/yml or json unless an explicit format flag chooses YAML or JSON; other extensions are Config. JSON and YAML have one schema and identical compiler semantics.

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| FR-033-AC-1 | An offline graph is validated and inspected with correct signatures/stages and zero backend/native calls. | Test (TC-033) |
| FR-033-AC-2 | A model graph can be inspected without credentials; an unavailable primitive is explicitly refused. | Test (TC-033) |
| FR-033-AC-3 | Equivalent YAML/JSON yield equivalent inspection; TOML/unknown extensions and malformed configs are refused. | Test (TC-033) |
