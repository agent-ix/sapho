# StR-007: Invoke evaluations on supplied data

## Stakeholder Need

The evaluation user requires that Sapho shall make run and inspect evaluations without writing a host program possible while retaining typed results and attributable evidence.

## Rationale

The existing embedding engine already evaluates code, model and logic stages. The user needs a reusable workflow around that engine, with domain meaning owned by the consumer.

## Validation Criteria

| ID | Criteria | Validation |
|----|----------|------------|
| StR-007-VC-1 | A documented example produces observable results through the owning module's public contract. | Demonstration |
| StR-007-VC-2 | Invalid input is distinguishable from a completed evaluation and never silently repaired. | Demonstration |
