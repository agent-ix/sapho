# TC-055: Run local Ollama models from CLI bindings

## Description

Verify [the functional contract](../functional/FR-055.md) through observable public behavior with original offline inputs and injected seams only.

## Test Procedure

1. Exercise FR-055-AC-1: load the binding with defaults and refuse unknown members, credential-like members and unknown providers.
2. Exercise FR-055-AC-2: record against a loopback double and replay the measure report offline.
3. Exercise FR-055-AC-3: the recording holds the reported model name and raw request and response bodies without a claim about answering weights.
4. Exercise FR-055-AC-4: inspection and replay construct no backend and read no environment.
5. Exercise FR-055-AC-5: backend refusals surface unchanged from live commands.
6. Exercise FR-055-AC-6: the base URL comes from the environment variable, or the default when it is absent or empty, an invalid value is refused, and it appears nowhere else.
7. Exercise FR-055-AC-7: a slow double meets the binding and run deadlines.
8. Exercise FR-055-AC-8: help and guide list the provider; default tests stay offline.
9. Exercise FR-055-AC-9: a build without the provider refuses with the host feature error.

## Expected Results

Values, response model names, raw bodies, refusals and request counts match the declared criteria. No model quality or live server availability is inferred from a loopback double.
