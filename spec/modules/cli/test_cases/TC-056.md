# TC-056: Evaluate and tune datasets of about fifteen thousand cases with explicit ceilings

## Description

Verify [the functional contract](../functional/FR-056.md) through observable public behavior with original offline inputs and injected seams only.

## Test Procedure

1. Exercise FR-056-AC-1: measure and tune a generated 15,000-case Dataset with the documented flags and an offline scripted backend.
2. Exercise FR-056-AC-2: refuse the Dataset without the flags, and a file above a lowered byte ceiling.
3. Exercise FR-056-AC-3: defaults and help text.
4. Exercise FR-056-AC-4: disjoint files give the same per-case results as their union.
5. Exercise FR-056-AC-5: fail on a peak memory above the stated bound and record the peak and the run time.

## Expected Results

Counts, refusals and limits match the declared criteria; the peak memory stays within its bound, and timings are reported, never asserted against a clock.
