# US-007: Invoke evaluations on supplied data

## Story

**As an** evaluation user
**I want** to run and inspect evaluations without writing a host program
**So that** I can use the same checked graph from a shell, CI job or my application.

## Acceptance Examples (Illustrative)

- Given a valid documented example, when I invoke this workflow, then I receive attributable results.
- Given invalid configuration or unavailable required data, when I invoke this workflow, then I receive an explicit refusal.

## Constraints (Contextual)

Domain extractors remain in consumer tools. Graph creation and local evidence retention do not grant permission to publish private examples or install agent hooks.

## Priority and Risk (Informative)

This is part of the first general CLI delivery. Ambiguous data, identity or label handling can invalidate later measurements.
