# StR-003: Bounded graph execution and collection identity

## Stakeholder Need

The Sapho engine SHALL execute dependent judgments over identified records within explicit limits.

## Rationale

This separates reusable engine mechanics from consumer policy so that I can build semantic interpretation pipelines without managing their scheduling myself.

## Validation Criteria

| ID | Criteria | Validation |
|----|----------|------------|
| StR-003-VC-1 | An application composes this capability using declared engine interfaces. | Demonstration |
| StR-003-VC-2 | An invalid invocation reports its cause without a fabricated successful result. | Demonstration |

## Stakeholders

Application authors and investigators consuming Sapho as Rust libraries.
