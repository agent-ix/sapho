# FR-030: Assemble records from graph values

## Description

The Sapho executor SHALL assemble a typed Record from explicitly bound named values.

## Inputs

The explicit typed inputs, options and limits named in Behavior. External files and JSON/YAML are validated before evaluation.

## Outputs

The declared typed result, or a structured refusal. Execution failures retain available partial evidence; absence of a result is never interpreted as a passing evaluation.

## Behavior

The record operation has kind record with no parameters. Its arbitrary named input ports determine exact record field types at compilation; result is a Record of those fields. An empty record is valid. Runtime fields contain the bound Values, and the output datum inherits all input sources. Guards retain the normal Optional contract. This is deterministic data construction, not filesystem discovery or code interpretation.

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| FR-030-AC-1 | A record assembled from two upstream ports has the declared fields, values and merged sources. | Test (TC-030) |
| FR-030-AC-2 | Empty records compile and execute; unknown fields in the operation payload are Config. | Test (TC-030) |
| FR-030-AC-3 | A later ask can consume the assembled Record; incompatible downstream field types fail compilation. | Test (TC-030) |
