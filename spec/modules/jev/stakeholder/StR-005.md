# StR-005: Hosted Jev backend adapter

## Stakeholder Need

The Sapho engine SHALL obtain typed model judgments through a replaceable backend.

## Rationale

This separates reusable engine mechanics from consumer policy so that my graph does not depend on a particular model client.

## Validation Criteria

| ID | Criteria | Validation |
|----|----------|------------|
| StR-005-VC-1 | An application composes this capability using declared engine interfaces. | Demonstration |
| StR-005-VC-2 | An invalid invocation reports its cause without a fabricated successful result. | Demonstration |

## Stakeholders

Application authors and investigators consuming Sapho as Rust libraries.
