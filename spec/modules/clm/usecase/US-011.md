# US-011: Evaluate with an alternative decision provider

## Story

**As a** graph operator **I want** to choose a decision provider **So that** I can evaluate and reproduce the same graph with the service available to my host.

## Acceptance Examples (Illustrative)

- Given an existing CLM service, when I evaluate Boolean, choice and score questions, then I receive the provider's reported evidence.
- Given recorded exchanges and no credentials, when I replay, then identical requests reproduce their answers.

## Options (Exploratory)

An embedding application configures its backend directly; the stock CLI resolves host environment and OS credentials. Both retain the same graph contract.

## Constraints (Contextual)

Provider deployment belongs to the host; users need to preserve evidence independently of a live model.

## Priority and Risk (Informative)

High priority. Main risks are schema drift, confidence reinterpretation and accidental credential use during offline evaluation.
