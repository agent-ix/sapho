# IT-006: Capture and replay CLM through the transport boundary

## Objective

Verify real CLM translation and host integration independently of model availability.

## Target Integration

Production CLM HTTP adapter → ephemeral loopback HTTP server → core response → recording → exact offline replay → runtime validation.

## Preconditions

An isolated temporary directory and ephemeral loopback listener; synthetic public test state. No real model, credentials or OS store.

## Inputs

One ordered Boolean/choice/score request and synthetic authoritative success/error bodies, including approximate complete distributions.

## Test Procedure

1. IT-006-SC-1: Capture the actual HTTP request and assert path, question/option order and true/false criteria.
2. IT-006-SC-2: Return known evidence and assert retained confidence/probability/usage without reinterpretation.
3. IT-006-SC-3: Record, close the transport, replay identically and validate under the request policy.
4. IT-006-SC-4: Change a replay identity and assert ReplayMiss; use explicit CLM binding metadata offline.

## Expected Results

Exact raw response preservation, reproducible accepted answers, policy-sensitive misses and no live dependency during replay. Transport failures retain typed redacted errors.
