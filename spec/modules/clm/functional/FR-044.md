# FR-044: Bound CLM HTTP calls

## Description

When a host configures a CLM backend, the adapter SHALL issue inference through bounded asynchronous HTTP transport.

## Inputs

Checked core requests or host-selected configuration; untrusted bytes are bounded and validated.

## Outputs

Typed responses or a structured refusal; private contents are excluded from diagnostics.

## Behavior

Host configuration owns base URL, optional redacted bearer secret, finite positive timeout, request/response byte ceilings and maximum in-flight requests. Defaults: 30 seconds, 1 MiB request, 8 MiB response, 4 in-flight requests. URLs require http/https, no userinfo/query/fragment; cleartext is allowed only for loopback. Endpoint is derived from the configured base /v1/systemone. Redirects and retries are disabled. Timeout includes queue acquisition, sending and streamed body decode. Request serialization is bounded before send, response chunks stop at the ceiling independent of Content-Length. Limits must be nonzero. No lock is held across await. Cancellation releases concurrency capacity.

401/403 maps Unauthorized, 429 RateLimited, 400/422 ServiceValidation, timeout DeadlineExceeded, size overflow LimitExceeded and other transport/status/decode failures BackendFailed or InvalidAnswer. Error messages and their Display text never include response bodies, credentials, request content, HTTP headers or secret-bearing URLs. Default tests use a native transport seam or ephemeral loopback HTTP service; no model/keychain/external network is required. Service availability/auth scopes/model behavior are host responsibilities; permission failures surface explicitly.

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| FR-044-AC-1 | The production HTTP client sends to an ephemeral loopback server with the configured path and optional authorization; redirects do not reach another destination. | Test |
| FR-044-AC-2 | Zero limits, non-loopback cleartext and URLs with userinfo/query/fragment are refused without sending. | Test |
| FR-044-AC-3 | Request/response ceiling boundaries and stalled calls refuse at their configured bounds; concurrency never exceeds the configured maximum and cancellation releases slots. | Test |
| FR-044-AC-4 | Unauthorized, rate limit, validation and service errors map to documented categories without echoing sentinel secrets or bodies; calls perform exactly one attempt. | Test |
