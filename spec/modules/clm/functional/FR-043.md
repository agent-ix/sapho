# FR-043: Translate CLM typed decisions

## Description

When a host submits a checked model request, the CLM adapter SHALL translate it to the authoritative System One wire contract.

## Inputs

Checked core requests or host-selected configuration; untrusted bytes are bounded and validated.

## Outputs

Typed responses or a structured refusal; private contents are excluded from diagnostics.

## Behavior

The request uses POST /v1/systemone with model, plain structured state and an ordered questions object. Boolean uses type noul and criteria true/false mapped from yes/no; choice uses ordered label/description criteria; score uses ordered levels. Source sidecars are excluded. The adapter rejects empty question blocks before transport. CLI binding model defaults to clm-latest for CLM only.

The response has model, answers and usage. Noul returns probability; choice returns choice, confidence and probabilities; score returns score, confidence, legend and probabilities. The adapter validates legend against requested levels and requires complete distributions for choice/score. It preserves every numeric provider probability, confidence and expected score, without normalization or recomputation. CLM confidence is top probability minus mean of the remaining probabilities; it is not top probability. Usage input_tokens, output_tokens and billing_units retain their distinct reported values in core Usage; billing_units is optional for other providers. The adapter rejects malformed JSON/types/unknown fields, duplicate keys, mismatched answer kinds/IDs, bad probabilities, inconsistent legends or model identity with typed errors. Runtime owns policy-sensitive semantic validation and raw evidence retention; valid wire but semantically invalid responses remain available to runtime.

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| FR-043-AC-1 | Boolean, choice and score reach the transport with exact authoritative field names, source-free state, declared question/option order and explicit model. | Test |
| FR-043-AC-2 | A response with confidence 0.4 and top probability 0.6 retains both unchanged, along with fractional score and all usage values. | Test |
| FR-043-AC-3 | Malformed/duplicate/unknown wire fields, wrong kind/IDs, invalid scalar probabilities, legend mismatch and incomplete distributions refuse safely; empty questions send nothing. | Test |
| FR-043-AC-4 | Strict versus approximate-complete policies preserve the same raw distribution and apply existing policy-sensitive validation and exact replay. | Test |
