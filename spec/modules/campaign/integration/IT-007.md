# IT-007: Campaign composition

## Objective

Prove reusable execution and durable state do not require EARS semantics.

## Target Integration

Campaign library, core/runtime/recording, CLI/TUI and a compiled downstream adapter.

## Preconditions

Offline backend seam, synthetic graph inputs, isolated temporary state and explicit finite limits.

## Inputs

One successful job, one failed response, one interrupted attempt and an explicit retry control.

## Test Procedure

1. Import and execute jobs. IT-007-SC-01: immutable results and separate failed outcomes exist.
2. Interrupt and reopen. IT-007-SC-02: no automatic redispatch occurs.
3. Submit and replay a retry control. IT-007-SC-03: exactly one linked attempt is created.
4. Seal a result through a domain extension. IT-007-SC-04: domain artifact and completion event are atomic.
5. Attach and detach dashboard. IT-007-SC-05: worker state is unaffected and terminal restored.

## Expected Results

All step criteria hold; failure denominators and original evidence survive. Consumer native replay is verified in the consumer repository rather than introducing a Quire dependency into Sapho tests.
