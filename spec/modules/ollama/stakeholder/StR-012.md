# StR-012: Label and extract with a local model server

## Stakeholder Need

Sapho SHALL give a dataset author one structured, schema-checked answer, or one set of typed answers with probabilities, per item from a model served by an already running local inference server, with every exchange attributable to the exact model and bytes involved.

## Rationale

Local models make labelling affordable at scale, but only if each call is small and complete, the context limit is measured in the model's own tokens, and an item that does not fit is recorded rather than crashing or silently truncated. Keeping the raw exchange and model digest lets every label be traced to what the model was sent and what it said.

## Validation Criteria

| ID | Criteria | Validation |
|----|----------|------------|
| StR-012-VC-1 | An author extracts records for a set of items from a running Ollama server and receives, for each item, either a schema-valid value with usage and raw bytes or a typed refusal such as too large. | Demonstration |
| StR-012-VC-2 | The default test suite demonstrates the same behavior against a loopback stand-in server with no model installed. | Demonstration |
