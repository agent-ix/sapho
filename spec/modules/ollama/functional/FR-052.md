# FR-052: Record model identity, usage and raw bodies

## Description

The Ollama adapter SHALL attach the model name and digest, the reported usage and the exact request and response bytes to every completed exchange.

## Inputs

- The server's model list from `GET <base>/api/tags`.
- Each generate response's `model`, `prompt_eval_count`, `eval_count`, `total_duration`, `load_duration`, `prompt_eval_duration` and `eval_duration`.

## Outputs

- `model`: the name the server reported and the digest the model list gives for it.
- `usage`: `input_tokens` from `prompt_eval_count`, `output_tokens` from `eval_count`, elapsed milliseconds from `total_duration`, `estimated_input_tokens`, `estimate_exceeded`, and the server's load, prompt and generation durations.
- `raw`: the request bytes exactly as sent and the response bytes exactly as received.

## Behavior

A label is only as traceable as its exchange: the digest says exactly which weights answered, and the raw bytes let anyone check what the model was sent and what it said.

- When a binding sends its first generate request, the adapter SHALL first read the server's model list and resolve the binding's model name to its digest.
- If the model list does not contain the binding's model, then the adapter SHALL refuse with `Config` and reason `model_not_installed`, sending no generate request.
- If the name reported by a generate response differs from the binding's model, then the adapter SHALL return `ModelMismatch` with the retained raw exchange.
- The adapter SHALL return the raw request and response bytes on every completed exchange, on success and inside every ExtractError raised after a response arrived.

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| FR-052-AC-1 | Against a loopback server, a successful extraction carries the listed digest, `input_tokens` and `output_tokens` equal to the reported counts, elapsed milliseconds from `total_duration`, and the three server durations. | Test |
| FR-052-AC-2 | The returned raw request bytes equal the bytes the server received, and the raw response bytes equal the bytes it sent. | Test |
| FR-052-AC-3 | A model absent from the model list is refused with `Config` and `model_not_installed`, and the server records no generate request. | Test |
| FR-052-AC-4 | A response naming a different model yields `ModelMismatch` with the raw exchange retained. | Test |

## Dependencies

- **Upstream**: [FR-049](FR-049.md) produces the exchange that is recorded.
