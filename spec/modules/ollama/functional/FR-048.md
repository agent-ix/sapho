# FR-048: Local Ollama typed inference

## Description

The Ollama adapter SHALL submit complete typed question/state requests to an explicitly configured loopback service and retain bounded raw exchange evidence independently of answer validity.

## Behavior

The host supplies model, loopback URL, timeout, request/response/context/output bounds. No service installation/download/training or domain questions. One asynchronous request per infer, redirects/retries disabled, concurrency one. Native /api/generate stream false with structured JSON answer output. Reported confidence is model self-report, not calibrated probability evidence; distributions remain absent unless actually supplied. No synthesized confidence or mass, no repairing labels, no arbitrary JSON completion fallback. Truncation/end-of-budget responses refuse. Model response identity comes from service, not the requested alias. Complete core validation remains authoritative. Raw request/response and HTTP status are captured with made-call status even when JSON/span validation fails. Preflight oversize has no made call. Combined capture capacity is bounded and insufficient capacity refuses before dispatch. All time bounds include queue and body. Endpoint credentials/query/fragments/non-loopback redirects are prohibited. Model/context truncation is prevented by conservative byte/token upper bound and output reserve; no owner shortening. Prompt instructions are source-untrusted data, not tool authority.

## Acceptance Criteria

| ID | Criteria | Verification |
|---|---|---|
| FR-048-AC-1 | Boolean/choice/score answers preserve actual returned values, missing distributions and model identity; missing confidence/unknown labels fail without fabrication. | Test |
| FR-048-AC-2 | Oversize input, invalid endpoint and inadequate capture budget refuse without dispatch. | Test |
| FR-048-AC-3 | HTTP200 invalid JSON, HTTP errors and truncation retain raw made-call receipts; exactly one request is issued. | Test |
| FR-048-AC-4 | Timeout/body caps apply during queue/send/read and redirects/retries are disabled. | Test |

## Dependencies

sapho-core only among workspace crates. Provider confidence is explicitly self-reported heuristic. [Ollama generate contract](https://docs.ollama.com/api/generate).
