# StR-004: Crisp logic and heuristic degree operations

## Stakeholder Need

The Sapho engine SHALL combine model evidence and deterministic facts with explicit mathematical operators.

## Rationale

This separates reusable engine mechanics from consumer policy so that I can explain how a heuristic conclusion was obtained.

## Validation Criteria

| ID | Criteria | Validation |
|----|----------|------------|
| StR-004-VC-1 | An application composes this capability using declared engine interfaces. | Demonstration |
| StR-004-VC-2 | An invalid invocation reports its cause without a fabricated successful result. | Demonstration |

## Stakeholders

Application authors and investigators consuming Sapho as Rust libraries.
