# StR-006: Exact recording and offline replay

## Stakeholder Need

The Sapho engine SHALL replay recorded judgments and inspect the steps that consume them.

## Rationale

This separates reusable engine mechanics from consumer policy so that I can reproduce engine behavior without another inference call.

## Validation Criteria

| ID | Criteria | Validation |
|----|----------|------------|
| StR-006-VC-1 | An application composes this capability using declared engine interfaces. | Demonstration |
| StR-006-VC-2 | An invalid invocation reports its cause without a fabricated successful result. | Demonstration |

## Stakeholders

Application authors and investigators consuming Sapho as Rust libraries.
