# IT-004: Offline execution replay

## Objective

Verify offline execution replay through actual public crate interfaces.

## Target Integration

The owning crate and its declared prerequisite crates, with a model backend or SDK transport injected only at the external inference seam.

## Preconditions

Rust 1.98.1; no model server or credentials. Original synthetic test inputs only.

## Inputs

A configured graph, supplied Datum inputs, registered native primitives and finite run limits.

## Test Procedure

1. IT-004-SC-01: Record a scripted backend run, export/load with limits, replace the backend with replay, then change the threshold and question independently.
2. IT-004-SC-02: Assert concrete output values, source IDs, refusal codes and external call counts.

## Expected Results

Original outputs repeat; threshold recomputes; changed requests miss without a live delegate.
